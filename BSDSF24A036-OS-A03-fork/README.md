# BSDSF24A036-OS-A03-fork — myshell

A simple UNIX command-line interpreter (shell) written in C for Operating Systems Programming Assignment 03.

## Build

```bash
make
```

## Run

```bash
./bin/myshell
```

Exit with `Ctrl+D`.

## Clean

```bash
make clean
```

## Directory Structure

- `src/` – C source files for the shell implementation
- `include/` – header files (`shell.h`)
- `obj/` – object files produced by the build
- `bin/` – the compiled `myshell` executable
- `Makefile` – the build script
